# Wi-Fi Manager & Automation Hub in C++ (ESP8266)

Цей проєкт реалізує надійний локальний хаб автоматизації та інтелектуальний менеджер підключення на базі мікроконтролера **Wemos D1 mini (ESP8266)**. Система забезпечує автоматичне перемикання між режимом робочої мережі та захищеним аварійним режимом конфігуратора (**Captive Portal**), синхронізацію часу за протоколом **NTP**, захист вебпанелі за допомогою **HTTP Basic Authentication**, а також неблокуюче керування виконавчим пристроєм (зуммером).

---

## 🚀 Основні можливості

* **Автоматичний менеджер підключення (Wi-Fi Manager / Captive Portal)**: 
  * При першому запуску або у разі недоступності роутера плата створює власну відкриту точку доступу `ESP8266_Config_Hub`.
  * Вбудований DNS-сервер перенаправляє всі запити користувача на сторінку налаштування мережі.
* **Неблокуюча архітектура (Finite State Machine - FSM)**: 
  * Повна відмова від блокуючих циклів `while` у робочому циклі, що запобігає спрацьовуванню сторожового таймера (WDT reset) та зависанням.
* **Синхронізація точного часу (NTP)**: Отримання актуального часу з серверів `pool.ntp.org` без використання додаткових апаратних модулів RTC.
* **Безпека вебпанелі (HTTP Basic Authentication)**: Обмеження доступу до панелі управління за допомогою логіна та пароля (`admin` / `secret123`).
* **Автоматизація за розкладом (NTP Timers)**: Виконання завдань (наприклад, звукових сигналів за будильником) у чітко заданий час.
* **Підтримка mDNS**: Зручний доступ до пристрою в локальній мережі за адресою `http://esp8266.local`.

---

## 🛠 Апаратне забезпечення та залежності

* **Мікроконтролер**: Wemos D1 mini (ESP8266)
* **Виконавчий пристрій**: Зуммер (підключений до піна `D1` / GPIO 5)
* **Середовище розробки**: VS Code + PlatformIO
* **Фреймворк**: Arduino

### Залежності (`platformio.ini`)
Для коректної компіляції проєкту необхідні такі бібліотеки:
```ini
[env:wemos_d1_mini]
platform = espressif8266
board = d1_mini
framework = arduino
monitor_speed = 115200
lib_deps =
    taranais/NTPClient @ ^3.2.1
